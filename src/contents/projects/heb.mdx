> ## What I Worked On

- Native Android development in Kotlin and Java
- ViewModels with MVVM architecture, and Shared Flows for state
- Navigation component with Nav Args, and coroutines for API calls
- GraphQL APIs called through repositories
- Frontend interfaces and backend services built with React, Next.js, and Python
- Unit tests for every part of the ViewModels, and regular code reviews
- End-to-end application support, including production issues
- Writing technology stack and standards reports and training guides

> ## What I Worked On

- Native Android development in Kotlin and Java, with UI built in Jetpack Compose
- Shared Flows for state, and RxJava for API calls
- Google Maps API integration
- Java Spring Boot backend services built with Maven, and a J2EE application
- Full-stack applications designed and built with React, Next.js, and Python
- Deployment with Jenkins, and API testing with Postman and Insomnia
- Unit tests, code reviews, and following coding standards
- Recommendations on system design, architecture, security, scalability, reliability, and performance
- Supporting the build and deployment pipeline, and diagnosing production issues
- Working closely with Product, Design, and QA to deliver the app to the client

> ## Overview

As a Software Engineering Senior Advisor at Cigna (October 2022 – March 2023), I worked on the native Android app for Accredo, Cigna's specialty pharmacy.

> ## What I Worked On

- Native Android development in Kotlin and Java
- UI development with Jetpack Compose
- ViewModels with MVVM architecture, plus MVP where needed
- Shared Flows for state
- Okta library integration for authentication
- HTTP API integration
- Unit tests for every part of the ViewModels, and regular code reviews
- Recommendations on system design, architecture, security, scalability, reliability, and performance
- Advising management on engineering matters, and writing technology stack and standards reports and training guides
